# Portfolio — RAJAONAH Mickaël (Mikami)

Portfolio personnel développé avec Next.js, présentant mon parcours, mes compétences techniques et mes projets.

🔗 **Live** : [portfolio-web-self-chi.vercel.app](https://portfolio-web-self-chi.vercel.app)

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Déployé sur Vercel

## Lancer le projet en local

```bash
npm install
npm run dev
```

Puis ouvrir [http://localhost:3000](http://localhost:3000).

## Structure
app/
layout.tsx 
# Layout global + metadata
page.tsx 
# Page d'accueil (profil, compétences, projets, contact)

# Styles globaux + thème sombre
